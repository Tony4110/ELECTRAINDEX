## Rules we keep
- An affiliate link never changes a score, a value label or a rank (`v_affiliate_flags` is not read by any ranking).
- Every affiliate button is labelled on the page and uses `rel="sponsored nofollow"`.
- No paid search ads on vendor brand names (most programs forbid it anyway).
